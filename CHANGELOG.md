# Changelog

## 0.2.0.dev0

- Construct separate micro and macro fragment artifacts in new analyses using the established two-level grouping rules.
- Preserve macro-to-micro and micro-to-event references, with at most 2,048 events per fragment.
- Select the requested fragment level through the existing read-only tools and expand exact event membership.
- Continue reading legacy phase-only catalogs without rewriting their contents.

## 0.1.0.dev0

- Initial standalone three-file input interface, evidence catalog, seven-agent investigation, reasoning, verification and final adjudication.
- Catalog queries used a single phase-fragment set for both micro and macro selectors.
